# Функциональная спецификация: немецкое слово → карточка Anki

## Назначение

Инструмент с текстовым интерфейсом (TUI), который по немецкому слову находит
грамматическую информацию в словаре, формирует карточку и добавляет её в
локальный Anki (через add-on AnkiConnect) в выбранный deck.

## Режимы работы

1. **Добавление слова** — пользователь вводит немецкое слово, программа создаёт
   новую карточку.
2. **Сканирование deck** — программа проходит по существующим карточкам выбранного
   deck, находит неполные (без перевода и нужной грамматической информации) и
   дополняет их автоматически.

## Сценарий: добавление слова

1. Пользователь запускает программу.
2. Выбирает целевой deck (из списка существующих в Anki) либо указывает его заранее.
3. Вводит немецкое слово.
4. Программа показывает найденную грамматическую информацию в виде предпросмотра
   будущей карточки.
5. Пользователь подтверждает добавление (или отменяет / редактирует).
6. Карточка добавляется в Anki, программа возвращается к вводу следующего слова.

## Сценарий: сканирование deck

1. Пользователь выбирает deck и режим сканирования.
2. Программа загружает все карточки deck и определяет неполные — те, где
   отсутствует перевод/определения или ожидаемая грамматическая информация
   (для существительного нет рода или множественного числа, для глагола нет
   Partizip II и т. п.).
3. Из каждой неполной карточки извлекается исходное немецкое слово (поле Front),
   по нему запрашивается словарь.
4. Программа показывает список найденных дополнений (что и в какие карточки будет
   добавлено) для просмотра.
5. Пользователь подтверждает применение целиком или отбирает отдельные карточки.
6. Программа обновляет поля карточек в Anki и показывает итог: сколько обновлено,
   сколько пропущено (не найдено в словаре / неоднозначно).

### Что считается «неполной» карточкой

- Пустое поле Back (нет перевода/определений), **или**
- Отсутствует грамматическая информация, ожидаемая для части речи слова
  (род и множественное число у существительных; Partizip II и вспомогательный
  глагол у глаголов; степени сравнения у прилагательных).

Карточки, у которых всё необходимое уже заполнено, пропускаются и не трогаются.

## Грамматическая информация по частям речи

Определяется часть речи, и в зависимости от неё извлекаются поля:

| Часть речи      | Извлекаемые данные                                              |
| --------------- | -------------------------------------------------------------- |
| Существительное | род (der/die/das), множественное число, русский перевод, определения |
| Глагол          | Partizip II, вспомогательный глагол (haben/sein), reflexive (sich), Präteritum, русский перевод |
| Прилагательное  | сравнительная и превосходная степени, русский перевод          |
| Прочее          | русский перевод, определения (базовый набор)                   |

Русский перевод (из секции `{{Übersetzungen}}`) извлекается для всех частей речи.

## Источник данных

Два взаимозаменяемых источника (одинаковая модель `lexicon.Word`, выбор флагом
`-dict`):

1. **Live API German Wiktionary** (`de.wiktionary.org`) — по умолчанию. Бесплатно,
   без ключа, всегда свежее. Минус: один HTTP-запрос на слово; при добавлении
   много слов подряд Wikimedia отдаёт **HTTP 429** (rate limit). Требует заголовок
   `User-Agent` (иначе 403).
2. **Офлайн-дамп kaikki.org (wiktextract)** — машиночитаемая выгрузка немецкого
   Викисловаря (`dewiktionary`, редакция Deutsch). Разово скачивается (~3 ГБ),
   `cmd/wikt-import` ужимает её в компактный JSONL (только немецкие леммы, только
   нужные поля), который грузится в память. **Ноль сети, ноль лимитов** — то, что
   нужно для массового добавления. Формы (Plural, Partizip II, Hilfsverb,
   Präteritum, степени сравнения), род и русские переводы лежат структурно.

Отвергнутый вариант: Free Dictionary API (`dictionaryapi.dev`) — немецкий покрыт
ненадёжно (404 на типовых словах), род и множественное число не структурированы.

Отвергнут как источник форм: Yandex/любой MT — это переводчик, отдаёт строку
перевода, но не грамматические формы; словарный API Яндекса закрыт.

## Формат карточки

Тип заметки Anki — «Basic» (поля Front/Back). Теги: `german`, `auto` для карточек
из словаря; `german`, `manual` для добавленных вручную (через `ctrl+e`).

Back строится в порядке: **русский перевод** (главное) → формы слова → немецкое
значение под разделителем `──` (опциональный контекст). Русский перевод берётся
из секции `{{Übersetzungen}}` той же страницы Wiktionary (строка `*{{ru}}:`),
ударения снимаются. Если перевода нет — строка просто отсутствует.

| Часть речи      | Front      | Back (сверху вниз)                                       |
| --------------- | ---------- | -------------------------------------------------------- |
| Существительное | `das Obst` | `фрукты` · `Plural: die …` · `──` · немецкое значение    |
| Глагол          | `lernen`   | перевод · `Partizip II: … · Hilfsverb: …` · `──` · знач. |
| Прилагательное  | `schön`    | перевод · степени сравнения · `──` · значение            |

Строка `Plural` опускается, когда у слова нет множественного (плейсхолдер `—`).

## Поведение интерфейса (TUI)

После выбора deck пользователь выбирает режим: добавление слова или сканирование.

Экраны режима **добавления слова**:

1. **Выбор deck** — список существующих deck'ов из Anki. Пропускается, если deck
   задан флагом запуска.
2. **Ввод слова** — текстовое поле, Enter отправляет запрос в словарь. `ctrl+e`
   добавляет слово **вручную, минуя словарь**: открывает редактор с уже
   заполненным Front (введённое слово) и пустым Back (курсор в поле Back), чтобы
   вписать перевод самому. Дальше работает обычный путь редактирования: `ctrl+s`
   → предпросмотр → `enter` добавляет карточку в Anki. Полезно, когда слова нет в
   словаре или нужна быстрая ручная карточка. `esc` из ручного редактора
   возвращает сразу к вводу слова (предпросмотра у ручной карточки нет),
   сохраняя введённое слово.
3. **Загрузка** — индикатор во время обращения к словарю.
4. **Предпросмотр** — отрисовка будущей карточки. Действия: добавить (`enter`/`y`),
   редактировать (`e`), отменить (`esc`/`n`).
5. **Редактирование** — форма с полями Front (однострочное) и Back (многострочное),
   заполненными из предпросмотра. `tab` переключает поле, `ctrl+s` сохраняет правки и
   возвращает в предпросмотр, `esc` отменяет правки. Теги не редактируются.

   При отмене из предпросмотра (`esc`/`n`) программа возвращается к вводу, **сохраняя
   введённое слово** в поле (как и при ошибке «не найдено»); после успешного
   добавления поле очищается под следующее слово.
6. **Результат** — сообщение об успехе (с идентификатором заметки) или об ошибке,
   затем возврат к вводу следующего слова.

Экраны режима **сканирования deck**:

1. **Сканирование** — индикатор: загрузка карточек и поиск дополнений в словаре.
2. **Список дополнений** — карточки с найденными дополнениями, по каждой видно, что
   будет добавлено. Действия: отметить/снять отдельные карточки, применить
   выбранные, отменить.
3. **Прогресс** — индикатор обновления карточек в Anki.
4. **Итог** — сколько обновлено, сколько пропущено (не найдено / неоднозначно).

### Оформление

Интерфейс цветной. Цвет несёт смысл, а не только украшает:

- статусы — успех (зелёный), ошибка (красный), пропущено/предупреждение (жёлтый);
- грамматика по роду — der/die/das разными цветами (мужской/женский/средний);
- акценты интерфейса — заголовки, выбранный пункт списка, активное поле ввода,
  горячие клавиши в подсказках.

Палитра — адаптивная к тёмной/светлой теме терминала; при отсутствии поддержки
цвета (не-TTY, `NO_COLOR`) интерфейс корректно деградирует до монохромного.

## Обработка ошибок

- Слово не найдено в словаре — в режиме ввода сообщение и возврат к вводу, при этом
  введённое слово сохраняется в поле ввода (курсор в конце), чтобы можно было
  исправить опечатку, не набирая заново; в режиме сканирования карточка
  пропускается и попадает в итог как пропущенная.
- Часть речи не распознана — карточка с базовым набором (определения).
- Anki/AnkiConnect недоступен или вернул ошибку — понятное сообщение пользователю.
- Дубликат заметки — поведение настраивается (по умолчанию запрет дублей).
- При сканировании карточки не перезаписываются полностью: дополняются только
  недостающие поля, уже заполненное не затрагивается.

## Внешние зависимости

- Запущенный Anki с установленным add-on AnkiConnect (локальный HTTP API,
  по умолчанию `http://localhost:8765`).
- Доступ в интернет к German Wiktionary.

## Параметры запуска

- Базовый URL AnkiConnect (по умолчанию `http://localhost:8765`).
- Опционально — целевой deck (иначе выбирается в TUI).
